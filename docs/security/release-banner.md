# 发行版安全公告横幅（发布规则）

> 用户规则（2026-10-28）：**后续连续 3 次新版本发布**，必须在发行版说明里加粗声明
> "1.0.3 之前的版本不安全，最好不要下载"。本文件是这条规则的唯一出处与执行记录。

## 1. 必须放在发行版说明的第一行（加粗）

中文（Gitee / npm / 中文说明）：

```markdown
> **⚠️ 安全公告：1.0.3 之前的版本存在安全缺陷，请不要下载或使用；请升级到 1.0.3 或更高版本。**
```

英文（GitHub / 英文说明）：

```markdown
> **⚠️ SECURITY NOTICE: Versions before 1.0.3 have known security defects. Do not download or use them — upgrade to 1.0.3 or later.**
```

## 3. 发布检查清单（每次发布勾一遍）

- [ ] 发行版说明**第一行**是上述加粗横幅（对应语言）
